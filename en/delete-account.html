Delete your Sanapolku profile

Delete the profile and related data in the Sanapolku app, or delete the server profile with a personal code on this page. Deletion requests are not sent by email.

1. Open Settings

Go to Privacy and support

Open Sanapolku Settings and select Privacy and support.

2. Choose deletion

Open Delete profile

Read the consequences and select Continue to deletion.

3. Confirm

Delete permanently

Confirm again with Delete profile permanently. The app tells you when the server has accepted the deletion.

Alternative without the app

Delete the server profile with a deletion code

Sanapolku shows your personal spdel1 deletion code under Privacy and support in Settings. Keep it private: it can delete your server profile, but it cannot be used to play, submit scores or reserve a nickname.

Use the code here if the app is no longer available. Web deletion removes the server profile and releases the nickname, but it does not clear app data from your device or bounded local caches on other devices.

The code starts with spdel1:. It is not stored in this browser.

An internet connection is required

The app verifies deletion with the secret stored securely on the device. If the connection fails before server confirmation, the old profile and local data remain so you can retry.

Permanent action

Deletion cannot be undone

A deleted nickname reservation, competition history, friends and achievements cannot be restored.

What is deleted?

The player row, nickname reservation, secret hash and private score data are deleted from the server. The deleted nickname becomes available for reservation again. The profile, history, friends, blocks, achievements, submission queue and saved results are deleted from the device.

An immutable result published before deletion may contain the UUID and nickname until the server and public CDN availability period of no more than 24 hours ends.

Server-side deletion does not remove a result from other devices’ local data. A device that already downloaded the result may retain its copy until it is evicted from that device’s public-result cache of up to 100 entries, the user clears app data, or the app is uninstalled.

After deletion, only a UUID tombstone remains on the server for 24 hours to prevent delayed requests. It contains no nickname or secret hash.

A new start

After successful deletion, Sanapolku returns to first registration and creates a new unregistered UUID and secret. The old profile is not linked to the new identity.

If the deletion menu is missing

Profile deletion is included in Sanapolku version 1.0. Update to the latest published app version. The ordinary support address does not accept profile deletion requests.
